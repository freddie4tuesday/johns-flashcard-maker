    Share the game

    The game file is a single web page with every card, your colors and your logo inside it. Put it online and anyone with the link can play on their phone.

    Instructions for putting it online

    The backup file and the game file are different. Use the backup to keep editing here. Use the game file to publish. A game file can also be imported here if you lose the backup.

    Backups are plain JSON files that include your cards, colors and logo. Game files are single web pages named index.html. Version 1.4.0.
